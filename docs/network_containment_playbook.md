# Automated Network Containment Playbook

---

## Introduction

The Automated Network Containment Playbook is designed to respond automatically to Endpoint Detection and Response (EDR) security alerts. It helps reduce response time by automatically analyzing incoming alerts and initiating network containment actions through the containment workflow.

This document explains the complete architecture, component responsibilities, data flow, and expected response generated by the system.

---

# Playbook Overview

The containment workflow begins when an EDR platform sends a webhook containing a security alert.

The alert is validated, parsed, analyzed, and processed through multiple components before a containment command is issued.

The workflow follows this sequence:

1. Receive EDR alert
2. Parse alert information
3. Orchestrate incident handling
4. Execute containment
5. Return containment response

# Component Responsibilities

## 1. Webhook

### Purpose

Receives incoming HTTP POST requests from the EDR platform.

### Responsibilities

- Accept incoming alerts
- Validate request
- Forward payload for processing

### Input

JSON alert

### Output

Parsed alert request

---

## 2. AlertParser

### Purpose

Extracts important information from the received alert.

### Responsibilities

- Parse JSON payload
- Extract hostname
- Extract IP address
- Extract severity
- Extract alert type
- Standardize alert format

### Output

Structured alert object

---

## 3. IncidentOrchestrator

### Purpose

Coordinates the complete incident response workflow.

### Responsibilities

- Receive parsed alert
- Decide containment action
- Call ContainmentService
- Collect response
- Return final result

---

## 4. ContainmentService

### Purpose

Executes network containment logic.

### Responsibilities

- Build containment request
- Call EDR client
- Process containment status
- Return containment result

---

## 5. MockEDRClient

### Purpose

Simulates communication with an actual Endpoint Detection and Response platform.

### Responsibilities

- Receive containment command
- Simulate device isolation
- Generate success or failure response
- Return containment status

  "action": "network_containment",

  "message": "Endpoint successfully isolated.",
  "timestamp": "2026-07-22T12:30:45Z"

# Summary

The Automated Network Containment Playbook provides a structured workflow for handling security alerts. By moving alerts through the Webhook, AlertParser, IncidentOrchestrator, ContainmentService, and MockEDRClient, the system automates endpoint isolation and produces a consistent containment response. This architecture improves response speed, reduces manual effort, and provides a clear foundation for future enhancements.
